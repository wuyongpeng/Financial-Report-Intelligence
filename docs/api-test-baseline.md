# API 重构安全网

本文说明架构重构前建立的自动化基线。目标是锁定当前公开行为，而不是证明当前接口设计或检索算法已经完善。

## 覆盖范围

### 快速契约测试

无需 PostgreSQL、已启动的 Next.js 服务或真实 LLM：

- API 错误状态、JSON 外形与 `no-store` 响应头；
- JSON、文本、UUID 和聊天请求输入边界；
- 当前会话追问、跨期、同行及关键词排序行为；
- SSE 的 LF/CRLF、网络分块、结束事件和不完整流；
- 模型增量输出、证据引用校验与安全降级。

执行：

```bash
npm run test:contracts
```

快速测试及相关文件 Lint：

```bash
npm run check:safety-net
```

完整既有测试集仍执行：

```bash
npm test
```

## 本地 HTTP 黑盒契约检查

黑盒检查通过 HTTP 访问真实 Route Handler、服务端业务逻辑及 PostgreSQL，覆盖：

1. 健康检查与数据库状态；
2. 报告列表成功响应及非法 `limit`；
3. 报告提纲、分析与不存在报告；
4. 会话创建、列表、读取、访客隔离、删除及删除后读取；
5. 聊天非法参数；
6. 聊天 SSE 的检索状态、最终结果及 `[DONE]`。

### 前提

- 本地 PostgreSQL 已启动并完成初始化；
- 数据库中至少有一份报告；
- Next.js 应用监听本机端口；
- 测试地址只能是 `localhost` 或 `127.0.0.1`，防止误写远程环境。

先启动本地应用：

```bash
npm run dev
```

在另一个终端执行：

```bash
npm run test:api-contract
```

如果应用不在默认的 `http://localhost:3000`：

```bash
API_BASE_URL=http://127.0.0.1:3001 npm run test:api-contract
```

黑盒脚本会动态选择已有报告，并只创建、删除自己的临时会话。它不会触发全量抓取、报告删除、管理员复核或批量智析。

## 结果解释

- “本地数据库没有报告”表示环境不满足测试前提，不应跳过后假装通过；
- 报告字段失败说明公开响应契约发生变化；
- 会话隔离失败属于安全回归；
- SSE 缺少最终结果或 `[DONE]` 会导致前端永久等待，属于协议回归；
- 当前关键词排序测试只是锁定重构基线，后续引入全文、向量或混合检索时，可以连同评测结果有意更新。

## 重构阶段的执行规则

每次迁移一个 API 或服务模块时：

```text
修改前运行快速契约测试
→ 完成重构
→ 再运行快速契约测试
→ 启动本地应用并运行黑盒契约检查
→ 最后运行完整测试、Lint、类型检查和构建
```

本安全网当前不覆盖真实模型答案质量。模型答案准确率、检索召回率和引用忠实度应由独立评测集负责，避免外部模型波动造成架构测试不稳定。
