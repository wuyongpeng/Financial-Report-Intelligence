# 决赛答辩 · 产品演示脚本（用例式）

整理日期：2026-10-27。  
依据：`docs/product-feature-list.md`（元功能列表）。  
定位：像软件工程里的**系统验收用例集**——有套件顺序、依赖理由、前置条件、步骤、期望结果、失败 Fallback；不是功能说明书的逐条巡演。

主样例公司：**东鹏饮料（605499）**（答辩期尽量选监控池外，走「纳入 → 采集 → 智析 → 追问」完整链）。

---

## 0. 总原则（怎么取舍）

1. **演示服务叙事，不服务功能穷举**。PPT 主张是「可验证 → 可信任」；现场只选能证明主张的链路。
2. **界面顺序 = 信任顺序**：先让评委看见「数据从哪来、原文在哪」，再让 AI 说话；语音与花活放在信任建立之后。
3. **一条主路径打穿，旁支用一句话点到为止**。列表懒加载、收藏、排序等不占用答辩主时间，需要时口头带过。
4. **每个用例都能当场判过/不过**。期望结果写到可观察的按钮文案、页面状态、角标行为；超时则走 Fallback，不空等。

---

## 1. 套件顺序与理由（先演哪一大块）

| 顺序 | 套件 | 覆盖功能块（对照功能列表） | 为什么先演 / 后演 |
|---|---|---|---|
| **S1** | 冷启动纳入 | §1 超级入口（自然语言 + 池外加入 + 立即抓取） | 先证明「不是只能看预置池」：评委提问任意正规公司时，系统能认名录、进监控、触发采集。这是后面一切的**前置依赖**（没有报告就没有三栏）。 |
| **S2** | 数据到达 | §2 数据采集页（多源状态、排队/并发、解析/智析） | 信任的第一层是**证据材料真实存在**。让评委看见发现→下载→解析→智析受控串行，而不是「黑盒里突然有了答案」。 |
| **S3** | 可验证阅读 | §3 三栏：概览角标 + 追问页码跳转 +（可选）划词 | **核心验收**：数字/结论能点回 PDF。对应 PPT「证据在前、解读在后」。时间不够时，S3 优先于语音与审计。 |
| **S4** | AI 有边界 | §3 边界策略（短答 + 软提示） | 在「会答」之后立刻演示「知道边界」——避免评委只记住模型能聊，却怀疑乱答。对应 PPT「AI 有边界」。 |
| **S5** | 实时语音 | §3 语音（跟页、答后定位、回首页换公司） | **体验加分项**。必须放在 S3 之后：先建立「可点回原文」，再展示「口述也能跳页」；否则语音像玩具。时间紧可整套砍掉。 |
| **S6** | 反馈闭环 | §4 审计（赞踩进审计） | **收尾可选**。证明产品不是一次性聊天，而是可回灌、可审计；通常 30–60 秒点到即可。 |

依赖关系（简图）：

```text
S1 纳入 ──► S2 采集就绪 ──► S3 可验证问答 ──┬──► S4 边界
                                           ├──► S5 语音（可选）
                                           └──► S6 审计（可选）
```

**不推荐**的顺序：一上来语音；或先聊很久 AI 再补出处；或把采集页演示拖成运维巡检。

## 2. 演示前 Fixture（环境用例前置）

| 检查项 | 期望 |
|---|---|
| 打开首页 | `http://127.0.0.1:3000/` 或线上答辩地址可访问；顶栏有「数据采集」 |
| 监控池 | **无** 605499（若已在池，换池外名企：百润 002568 / 洋河 002304 / 泸州老窖 000568） |
| 采集 | `autoCrawl` / 页上「自动智析」开启；worker 在跑；可预开 `/sources` |
| 期次 | 优先已智析的最新正式报告（如 `2026H1`；无则用表内最新已智析期次） |
| 语音（若演 S5） | Chrome 麦克风选本机，非 Continuity 手机麦 |
| 文案禁忌 | 不说「立即导入」「立即添加」；正确：**加入监控池** / **立即抓取** / **立即采集** |

超时策略：S2 超过约 1–2 分钟仍无「智析」→ 切已接入公司（如茅台 600519）续做 S3–S5，旁白说明「采集链路已演示，阅读验证用现成样本」。

## 3. 用例明细

### S1 · 冷启动纳入

#### TC-S1-01 自然语言认公司并加入监控池
- **目的**：验收超级入口「提问即找公司 + 池外纳入」。
- **映射功能**：§1 检索与提问 / 池外纳入。
- **前置**：首页已开；池内无 605499。
- **步骤**：
  1. 输入并发送：`东鹏饮料最新业绩好不好`
  2. 弹窗点 **加入监控池**
- **期望**：
  - 弹窗识别「东鹏饮料」（605499），文案表明不在监控池
  - toast 类似「已将「东鹏饮料」加入监控池」
  - 出现等待抓取态空卡片
- **旁白一句**：自然语言先做 A 股名录识别，再决定是否进池——入口统一，不必先记代码。
- **失败**：识别错公司 → 改用代码 `605499` 再试；仍失败则换 Fallback 公司。

#### TC-S1-02 立即抓取进入采集页
- **目的**：验收从首页卡片触发温和采集，并落到数据采集页。
- **映射功能**：§1 立即抓取；§2 `/sources?focus=`。
- **前置**：TC-S1-01 通过。
- **步骤**：在东鹏空卡片点 **立即抓取**。
- **期望**：进入 `/sources?focus=605499`（或等价聚焦）；队列中可见该公司相关任务。
- **旁白一句**：纳入只是登记；真正信任从「去源站拿 PDF」开始。
- **备选**：带期次提问触发「尚未下载 → **立即采集**」（只触发、不跳转时，再点顶栏「数据采集」）。

---

### S2 · 数据到达

#### TC-S2-01 多源健康与队列可见
- **目的**：验收采集页不是黑盒，链路状态可观测。
- **映射功能**：§2 数据源连接状态、排队/并发、解析/智析。
- **前置**：已在 `/sources`；自动抓取/智析开着。
- **步骤**：
  1. 指出 SSE / SZSE / BSE / 巨潮等源与小绿点
  2. 指出排队下载、下载中（如 x/5）、解析、智析状态
  3. （可选，5 秒）点开「采集设置 / 自动抓取」说明可降并发、可暂停，防反爬
- **期望**：评委能说出「发现→下载→解析→智析」四步；并发有上限。
- **旁白一句**：间隔与并发受控——稳比猛更重要，否则源站一封，整天没数据。
- **不演**：删除、手工再解析的细操（口头：运维可重跑）。

#### TC-S2-02 智析就绪后进入三栏
- **目的**：验收「材料就绪 → 阅读工作台」跳转。
- **映射功能**：§2 期次链接进详情；§3 期次。
- **步骤**：表中点优先期次（有 `2026H1` 用它，否则最新已「智析」期次）。
- **期望**：进入 `/{code}?period=…` 三栏详情；左 PDF、中概览、右追问。
- **旁白一句**：智析完成后**手动**进详情——阅读是用户主动打开证据，不是系统塞结论。
- **失败**：无智析 → Fallback 已接入公司；旁白「以已入库最新正式报告为准」。

---

### S3 · 可验证阅读（核心，不可砍）

#### TC-S3-01 概览数字点回原文
- **目的**：验收中栏「关键数据 + 页码角标 → PDF 跳页高亮」。
- **映射功能**：§3 概览关键数据、出处角标。
- **步骤**：在中栏找一带页码角标的关键指标，点击角标。
- **期望**：左栏 PDF 跳到对应页并高亮相关区域。
- **旁白一句**：先证据后解读——界面顺序就是信任顺序。

#### TC-S3-02 追问答案带出处并可跳转
- **目的**：验收右栏问答「结论可定位原文」（主主张）。
- **映射功能**：§3 可验证答案、生成中态。
- **步骤**：提问  
  `本期营业收入和归母净利润分别是多少？同比怎么样？`  
  答出后点文内 **`[页码]`** 角标。
- **期望**：流式/等待态可见；答案含页码引用；点击后 PDF 跳页高亮。
- **旁白一句**：每个关键数字都该能点回原文；不敢点的数字，就不敢引用。
- **备选题**：`毛利率是多少？变化原因？`

#### TC-S3-03（可选）划词组合上下文
- **目的**：点到「用户指定证据再问」。
- **映射功能**：§3 划词加入 AI、组合上下文。
- **步骤**：PDF 划一段 → 加入 AI 分析（或双击卡片）→ 追问一句。
- **期望**：追问上下文带上所选片段；回答仍尽量带出处。
- **时间盒**：整段 ≤ 40 秒；不够就跳过。

#### TC-S3-04（可选）事件题不编造
- **目的**：有出处则答，无则承认依据不足。
- **步骤**：问 `姆巴佩事件对财报影响有多大`
- **期望**：能从代言/营销/费用等原文作答，或明确依据不足；不编造未披露因果。
- **旁白一句**：热点可以问，但不能替财报发明故事。

---

### S4 · AI 有边界

#### TC-S4-01 题外话短答 + 软提示
- **目的**：验收边界是软的，不是硬拒。
- **映射功能**：§3 边界策略。
- **步骤**：问 `明天天气怎么样`（或简短题外话）。
- **期望**：先有短答；文末/脚注含类似「此问题可能超出当前财报范围…」；**不**甩一长段 KPI 充数。
- **旁白一句**：边界切太死会误伤追问；天气看似无关，对农业航运等也可能动业绩——所以软提示，不硬掐。
- **PPT 挂钩**：P6「AI 有边界」。

---

### S5 · 实时语音（时间紧可整套跳过）

#### TC-S5-01 跟页口述 + 答后跳转
- **目的**：验收语音不是另一套产品，而是同一套「可验证」交互。
- **映射功能**：§3 连续对话、跟页提问、答后定位。
- **前置**：S3 已让评委见过角标跳转；Chrome 本机麦。
- **步骤**：进入语音 → 翻到某页 → 口述该页相关短问 → 听完看是否跳页高亮。
- **期望**：短答；答后 PDF 定位；可打断。
- **旁白一句**：刚才鼠标点角标，现在口述也能落到同一处原文。

#### TC-S5-02（可选）语音回首页换公司
- **目的**：验收跨页会话保持。
- **步骤**：说「返回主页」类指令 → 首页仍有语音浮层可继续。
- **期望**：不掐断会话；可再问另一家（点到即可，不必真采完）。
- **失败**：浮层消失 → 口头承认已知问题/已修版本，不现场死磕。

---

### S6 · 反馈闭环（可选收尾）

#### TC-S6-01 赞踩进入审计
- **目的**：验收「用户纠错 → 可审计」。
- **映射功能**：§3 反馈；§4 审计。
- **步骤**：对任一答案点赞或点踩 → 打开 `/admin/audit`（密码遮罩输入）→ 看到对应反馈事件。
- **期望**：审计列表出现反馈类记录；密码不明文。
- **旁白一句**：信任还靠持续校准——现场反馈会进审计，可回放、可回灌。
- **时间盒**：≤ 45 秒。

## 4. 推荐时间盒（约 6–8 分钟产品演示）

| 段 | 套件 | 建议时长 |
|---|---|---|
| 纳入 + 抓取 | S1 | 45–60s |
| 采集页指认 | S2 | 45–60s |
| 角标 + 追问出处 | S3（01–02 必做） | 2.5–3.5min |
| 边界 | S4 | 30–40s |
| 语音 | S5 | 0–90s（可砍） |
| 审计 | S6 | 0–45s（可砍） |

**保底路径（只有 4 分钟）**：S1 口头带过或用已接入公司 → **S3-01 + S3-02 + S4**。  
**加时路径**：+ S2 全貌 + S5-01。

## 5. 功能列表覆盖矩阵（防漏讲 / 防贪讲）

| 功能列表章节 | 主路径是否演示 | 策略 |
|---|---|---|
| §1 检索多形态（简称/拼音等） | 点到即可 | 东鹏全称已够；拼音/简称作「同样支持」一句 |
| §1 收藏 / 懒加载 / 行业筛选 | 不演示 | 非信任主链 |
| §1 语音入口 | 并入 S5 | 勿在 S1 抢戏 |
| §2 多源 / 队列 / 开关 | S2 演示 | 设置项口头 |
| §2 再抓取/再解析/删除 | 不演示 | 运维能力，答辩不展开 |
| §3 提纲/搜索/缩放/收起 | 不演示或 5 秒 | 保 S3 出处 |
| §3 深度归因 | 可选扫一眼 | 有料再指，无则跳过 |
| §3 重答/长短/复制/推荐问题 | 不演示 | 工具性，非主张 |
| §3 语音全套 | S5 | 可砍 |
| §4 审计 | S6 | 可砍 |

## 6. Fallback 速查

| 现象 | 动作 |
|---|---|
| 东鹏已在池 | 换百润 / 洋河 / 泸州老窖，用例步骤不变 |
| 采集太慢 | S1+S2 队列演示完 → 切茅台等已智析公司做 S3–S5 |
| 无 2026H1 | 用最新已智析期次；旁白「以已入库最新正式报告为准」 |
| 立即采集不跳转 | 再点顶栏「数据采集」或空卡片「立即抓取」 |
| 语音不稳定 | 跳过 S5，用 S3 角标证明同一跳转能力 |
| 审计登录不便 | 跳过 S6，口头说明赞踩会入库 |

## 7. 与 PPT 页的挂钩（讲的时候别两张皮）

| 演示套件 | 更贴哪类 PPT 主张 |
|---|---|
| S2 采集 | 数据直通、材料真实、过程可看 |
| S3 角标/出处 | 「准确率不是 100% → 所以必须能点回原文」；可验证所以可引用 |
| S4 边界 | 「AI 有边界」；软提示优于硬拒 |
| S5 语音 | 易用 / 主路径体验（信任已立住后再秀） |
| S6 审计 | 守护信任：反馈回灌、可审计 |
