# 产品介绍

整理日期：2026-10-28。  
产品名：**Eva（财报智析）**——面向 A 股上市公司财报的智能阅读与分析工具。

## 一句话

把交易所公开财报 PDF，变成**可查询、可对比、可点回原文**的阅读台。主张是「问财报，有出处」，不是替人下买卖结论。

## 适合谁

- 需要快速看懂一家公司最新正式报告的经营表现
- 需要核对数字是否来自官方披露，而不是只能信摘要
- 需要围绕同一份报告追问变化原因，并回到 PDF 页核对

不适合：寻求荐股、目标价或「能不能买」的结论。产品不做证券买卖建议。

## 核心能力（已实现）

| 能力 | 说明 |
|---|---|
| 找公司进财报 | 首页按全称、代码、简称、拼音检索；可收藏、按行业筛选 |
| 一站式三栏阅读 | 左栏 PDF 原文 · 中栏结构化概览 · 右栏带出处的追问 |
| 四项核心指标 | 营业收入、归母净利润、基本每股收益（EPS）、净资产收益率（ROE）；保留字段名与页码 |
| 角标回原文 | 指标与问答中的页码可跳左栏并高亮，方便核验 |
| 指标联动 | 程序核对少数硬关系（收入×利润、利润×现金流、归母×扣非），展开看数据与提示 |
| 多期趋势 | 仅用已入库真实报告期；同比用上年同期，季报与年报不混算 |
| 深度归因 | 结合行业维度解读变化；有料优先 |
| 智能追问 | 结构化数据 + 页文本证据；答案带页码；题外话短答 + 软提示 |
| 实时语音 | 连续口述提问、跟页、切期次；可结束会话 |
| 数据采集 | `/sources` 看清发现 → 下载 → 解析 → 智析；多源、温和并发 |
| 状态透明 | 已上线 / 待复核 / 部分解析等如实展示，不拿模拟数填空 |

## 主路径怎么用

1. 打开应用，搜索公司，或从推荐样本进入一份指标较完整的财报。
2. 先看四项核心指标与财报速览；点角标回 PDF 核对。
3. 需要时展开「指标联动」，看程序算出来的关系事实与提示。
4. 在趋势里切换指标，只看已入库期次。
5. 右侧追问变化原因；点答案页码回原文。
6. 池外公司：按引导加入监控池 / 立即抓取，等解析完成再问。

## 数据与边界

- 来源：上交所、深交所、北交所、巨潮等官方公开渠道；增量采集、公告去重。
- 缺数据就空着或标明状态，不编造指标，不假装「80 类关系都查过」。
- 图表、同业比较、问答都只使用页面标明的真实范围。
- 文档中心入口为手动访问 `/docs`（首页不展示按钮）。
