# 财报分析说明

整理日期：2026-10-28。  
说明 Eva **怎么读财报、哪些已上线、哪些只是规划**。分析以可核验为先：程序算事实，规则找关系，模型按需解释原文；彼此不互相阻塞。

## 1. 分析分层

| 层 | 回答的问题 | 谁做 |
|---|---|---|
| 四项核心指标 | 数字是多少？出处在哪一页？ | 规则抽取 + 页码 |
| 财报速览 | 对本期整体怎么概括？ | 模型综合评价（独立任务） |
| 指标联动 | 哪些数字要一起看？能说明什么、不能说明什么？ | 程序关系 + 短提示（只读） |
| 趋势 / 归因 | 多期怎么走？行业上有什么线索？ | 已入库数据 + 行业提示 |

一句话：**确定的走规则，不确定的解读走 AI，并且都要能回到原文。**

## 2. 核心指标与状态

抽取重点：营业收入、归母净利润、EPS、ROE。每条尽量保留原始字段名、页码、置信度与是否人工复核。

| 状态 | 含义 |
|---|---|
| 已上线 | 管理员复核通过 |
| 待复核 | 机器已抽出四项，待人工核验 |
| 部分解析 | 只抽出部分指标；页面不补造缺失值 |
| 待处理 / 已下载 | 已发现公告，仍在下载或解析 |

同比口径：用**上年同报告期**；Q1、Q3、半年、全年不混算。

## 3. 指标联动（已实现）

组名：**指标联动**。位置在四项核心指标下方、指标趋势上方。

### 原则

- 程序发现关系，模型辅助解释——不是又一张指标卡，也不是又一段 AI 总结。
- 每条默认折叠；展开为两行：**数据**（尽量带 `[Pxx]` 角标）+ **提示**；只读，无追问按钮。
- 规则可多于展示：约 **10 类**检测器注册；界面最多 **3** 条，按关注度排序并做主题去重（例如现金质量主题只留更严重的一张）。
- 「已上线」指仓库已接入业务界面，不代替线上部署验证。

### 当前已注册关系（约 10 类）

| 关系 | 帮用户理解 | 何时出卡（摘要） |
|---|---|---|
| 营收 × 归母净利润 | 收入增长有没有转化为利润？ | 同比符号背离；或两边同比均 ≥5% 的同步增长 |
| 归母净利润 × 经营现金流 | 盈利与现金流是否匹配、走势是否分化？ | 跨期分化 / 净现比恶化 / 利润+且 OCF−；也可展示同步改善；无上期时退回本期阈值 |
| 归母净利润 × 扣非净利润 | 盈利中有多少来自非经常性损益？ | 非经常性占比 ≥20%，或扣非后为负；缺字段则跳过 |
| 营收 × 营业成本 × 毛利率 | 成本是否快于收入、毛利是否收窄？ | 毛利率同比下滑 ≥3 个百分点，或成本增速明显快于营收 |
| 收入变化 × 净利率 × 利润变化 | 利润变动里规模与利润率谁贡献更大？ | 两因子利润桥有结构看点（利润率主导 / 反向 / 利润下滑且利润率拖累） |
| 总负债 × 总资产 | 杠杆水平及跨期变化 | 资产负债率 ≥70%，或较上期上升 ≥5 个百分点 |
| 受限货币资金 × 货币资金 | 账面现金受限程度 | 受限占比 ≥30% |
| 商誉 × 归母权益 | 商誉相对权益体量 | 商誉 / 归母权益 ≥20% |
| 总资产增长 × 营收增长 | 资产扩张是否快于业务增长 | 资产扩张而营收下滑，或资产增速明显高于营收增速 |
| 营收 × 经营现金流率 | 每单位收入的经营现金是否走弱 | 经营现金流率跨期明显下降（与净现比主题去重） |

实现：`lib/metric-relationships.ts`（阈值复用 `FOCUS_THRESHOLDS` 等）。展示上限 3 条。

### 空态（整块仍显示）

| 状态 | 文案 |
|---|---|
| 已检查、无明显背离 / 值得列出的同步 | **已检查的关系未发现明显背离**（禁止写「暂无风险」） |
| 已注册关系均缺可比数据 | **缺少可比数据，暂无法判断** |

### 明确不做

- 投资建议 / 买卖点  
- 批发复活旧「重点关注」多维排雷  
- 把 MD&A 自动写成已证实原因  
- 无出处的「可能存在风险」空话  
- 把「约 10 类已注册」说成「已检查完整 80 类目录」

## 4. 规划中：更广的关系目录（未全量上线）

内部保留过「约 80 类」候选目录与扩展验收标准（现归档备查）。要点：

- **当前约 10 类已注册，不是已经检查了 80 类。**
- 目录展示 ≠ 规则已执行；未实现项不得统计为「已检查」。
- 扩展原则仍是：程序算事实、规则找关系、AI 解释原文；基础解析不因关系任务失败而卡住。
- A 级「字段可能够算」≠ 已验收上线；覆盖率与真值验证前不能当现网能力宣传。

对外答辩与产品页可承诺 **指标联动（程序核对已注册硬关系，界面最多 3 条）+ 四项指标可溯源**；继续扩展仍按独立规则逐项落地后再改本文。

## 5. 程序与 AI 怎么分工

| 工作 | 程序 | AI |
|---|---|---|
| 单位、期间、归属口径 | 校验；不一致则停止相关计算 | 不可绕过校验改数 |
| 加减、比例、同比 | 唯一计算权威 | 不重写计算结果 |
| 是否命中数值关系 | 版本化规则 | 不改命中状态 |
| 原因与原文解释 | 有界检索与出处校验 | 按需写短解释；无支持则待核验 |
| 缺披露 | 明示缺项 | 不猜数字、不把未披露当零 |

关闭模型时，程序关系与核心指标仍应可读；解释失败不得覆盖已有程序结果。

## 6. 使用与评分边界（摘要）

- 同业百分位等仅基于已覆盖样本，不是信用评级。  
- 净利润瀑布等恒等分解说明贡献结构，不等于经营因果证明。  
- 未解析业务分部 / 费用明细时，不生成替代数字。
