# 财报智析台产品介绍

财报智析台是一款面向 A 股上市公司财报阅读与分析的智能工具。产品持续采集上交所、深交所等官方公开公告，将财报 PDF 转化为可查询、可对比、可溯源的数据内容，帮助用户更高效地理解公司经营表现。

## 核心能力

- **一站式财报阅读**：搜索公司即可查看已入库财报、核心数据和原文内容。
- **核心指标提取**：自动识别营业收入、归母净利润、基本每股收益（EPS）和净资产收益率（ROE）。
- **数据可追溯**：每项指标均保留原始字段、页码和 PDF 核验入口，方便回到原文确认。
- **趋势与同业对比**：基于已解析的真实报告期数据，查看多期趋势及同业指标表现。
- **智能问答辅助**：围绕财报内容提出问题，系统结合结构化数据和原文证据给出带页码依据的回答。
- **质量与状态透明**：明确展示已上线、待复核、部分解析等数据状态，不以模拟数据填补缺失信息。

## 产品特点

财报智析台坚持“真实数据、原文可查、结论有据”的原则。系统通过温和、合规的增量采集获取官方公开披露文件，并保留完整的数据来源链路；对于尚未充分解析或复核的数据，产品会如实展示边界，而不会生成未经证实的结论。

产品适合需要快速阅读上市公司财报、跟踪核心经营指标、进行基础同业比较和核验财报原文的用户使用。产品不提供证券买卖建议，所有数据分析和问答内容仅用于信息参考。
