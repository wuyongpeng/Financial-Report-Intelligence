# 财报智析台使用说明

## 用户体验路径

1. 打开应用即可使用（普通用户路径，无需评委专用入口）。
2. 在首页搜索公司，或点击“推荐完整样本”直接进入一份四项指标完整的财报。
3. 先查看营业收入、归母净利润、基本每股收益和净资产收益率。点击指标可查看原始字段、页码和 PDF 核验入口。
4. 在“核心指标多期趋势”中切换指标，仅查看系统已入库的真实报告期数据。
5. 在“同行业真实数据对比”中切换 ROE、营业收入或归母净利润。比较范围仅限绿色通道中同报告期已解析公司。
6. 点击“提纲阅读原文”，选择章节或页码，查看原文页文本并在 PDF 中核验；也可点击“追问本页”。
7. 在右侧问答区输入问题，例如“管理层如何解释本期净利润变化？”。点击回答下方的“第 N 页”证据卡，会自动展开对应原文并高亮命中片段。

## 数据状态说明

- 已上线：经管理员复核的指标。
- 待复核：机器已提取四项核心指标，等待人工核验。
- 部分解析：只提取到部分指标，页面不会补造缺失值。
- 待处理／已下载：已发现公告，后台任务仍在下载或解析。

## 使用边界

产品不提供买卖建议。图表、同业比较、异常提示和问答只使用页面明确标注的真实数据范围；没有足够真实数据时显示空态，不生成模拟结论。

## 公司详情页：三栏联动

- 左栏展示该公司的已解析财报，默认打开最新报告期。切换后，数据概览与问答均改用该期；旧回答会取消并清空，避免串期。
- 中栏默认展示四项核心指标、近五期同类型趋势、财务健康度与固定六轴同业雷达。同比严格使用上年同报告期；Q1、Q3、半年和全年不混算。
- 来源角标会定位左栏对应页；PDF 版式使用实际文本坐标高亮，支持放大阅读，也可切换到完整页文本与提纲导航。无法加载原始版式时保留文本及原始 PDF 入口。
- 右栏默认提供本期摘要、数据提示及四个推荐问题。配置模型后生成带页码的 AI 概览；未配置或失败时回退到明确标注的数据摘要。
- 利润原因、业务构成、异常、历史、同行问题会展开并定位中栏对应模块。小屏幕通过“来源 / 数据概览 / 对话”标签切换。

### 数据与评分边界

健康度目前只在数据足够时提供 ROE、营收同比增速的同业百分位。偿债能力、现金流质量缺少已解析指标，因此显示暂不评分。六轴固定为营收规模、利润规模、EPS、ROE、归母净利率、营收增速；缺失轴不会填零或闭合连线。百分位仅基于已覆盖同业样本，不是信用评级。

净利润瀑布采用“营业收入 × 归母净利率”的恒等分解：收入贡献为收入变化乘以上年归母净利率，其余变化归入净利率贡献。它不把整体费用虚构分摊到业务线，也不表示因果关系。尚未解析业务分部和费用、税率明细时，业务图及更细归因不生成替代数字。

本地验证需配置 PostgreSQL、财报归档路径及模型接口。构建与单元测试不代表已完成真实财报问答准确率或 PDF 浏览器验收。
