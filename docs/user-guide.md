# 财报智析台使用说明

## 评委体验路径

1. 打开首页的“财报绿色通道”，查看公告发布时间、系统发现时间和当前处理状态。
2. 点击任一已解析财报进入详情，先查看营业收入、归母净利润、基本每股收益和净资产收益率。点击指标可查看原始字段、页码和 PDF 核验入口。
3. 在“核心指标多期趋势”中切换指标，仅查看系统已入库的真实报告期数据。
4. 在“同行业真实数据对比”中切换 ROE、营业收入或归母净利润。比较范围仅限绿色通道中同报告期已解析公司。
5. 点击“提纲阅读原文”，选择章节或页码，查看原文页文本并在 PDF 中核验。
6. 在右侧问答区输入问题，例如“管理层如何解释本期净利润变化？”。回答仅基于本报告结构化指标、财报原文片段及已覆盖同行信息。

## 数据状态说明

- 已上线：经管理员复核的指标。
- 待复核：机器已提取四项核心指标，等待人工核验。
- 部分解析：只提取到部分指标，页面不会补造缺失值。
- 待处理／已下载：已发现公告，后台任务仍在下载或解析。

## 使用边界

产品不提供买卖建议。图表、同业比较、异常提示和问答只使用页面明确标注的真实数据范围；没有足够真实数据时显示空态，不生成模拟结论。
