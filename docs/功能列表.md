# Eva（财报智析）功能列表

整理日期：2026-10-27。范围：当前产品已实现能力的盘点（首页 / 数据采集 / 详情三栏 / 审计），供答辩、联调与后续迭代对照。文案已润色；功能点以现网/本地实现为准，不含规划中能力。

---

## 1. 首页 · 超级入口

面向「找公司 → 进财报 → 开始问」的主路径入口。

### 检索与提问
- **公司检索**：支持全称、股票代码、简称（如「工行」）、拼音等常见输入。
- **自然语言提问**：可直接输入问题；识别到公司后进入详情页追问。
- **池外纳入**：识别到 A 股名录内、但不在监控池的公司时，引导「加入监控池」；空卡片可「立即抓取」进入数据采集。
- **语音输入**：首页支持语音提问，并与全局语音悬浮框共用会话。

### 公司卡片与列表
- **收藏（Star）**：可收藏关注公司。
- **快捷进入**：已接入财报的公司可一键进入详情。
- **可视化懒加载**：卡片列表按滚动逐步加载，减轻首屏压力。
- **行业分类 / 排序**：按行业筛选，支持排序与网格/列表视图切换。
- **多期快捷跳转**：卡片上可跳到关心的报告期次。
- **关键数据悬停**：鼠标悬停可查看卡片上的关键指标摘要。

## 2. 数据采集页（`/sources`）

顶栏「数据采集」入口（旧 `/crawl` 会重定向至此）。用于看清「发现 → 下载 → 解析 → 智析」全链路。

### 数据源与连接
- **多源**：上交所（SSE）、深交所（SZSE）、北交所（BSE）、巨潮等公开渠道。
- **连接状态**：小绿点表示连接健康；可点击跳转对应官网。

### 采集控制
- **温和并发**：默认并发约 5，带排队，降低反爬与源站压力（界面可见「排队下载」「下载中 x/5」一类状态）。
- **自动抓取开关**：遇反爬或需暂停时可临时关闭自动抓取 / Cron 类定时任务。
- **采集设置**：可调整并发等采集参数。
- **AI 连通性**：可快速探测当前 AI 配置是否可用。

### 任务列表
- **按公司过滤**：点击公司名快捷过滤列表。
- **进详情**：点击期次链接直接进入三栏详情页。
- **再抓取 PDF**：可对目标期次再次触发下载。
- **再解析 / 再智析**：支持手动重跑解析与智析。
- **删除**：可删除不当或失败的任务/记录（按现页能力操作）。

## 3. 详情页 · 三栏阅读（原文 / 概览 / 追问）

正式财报的主工作台：左栏 PDF 原文、中栏结构化概览、右栏 AI 追问。

### 顶部与原文（左栏）
- **期次切换**：一键切换同一公司的不同报告期。
- **提纲**：可查看原文目录/提纲，辅助定位章节。
- **原文搜索**：在 PDF 内快速搜索关键词。
- **栏位收起**：支持抽屉式收起栏位；三栏最多收起两栏，避免布局挤乱。
- **视窗缩放**：来源栏仅 − / + 两钮，共 5 档（默认±两档，约 12%/档）；语音「放大一点 / 缩小」同档步进，「适合宽度 / 实际大小」回默认档；语音是快捷入口而非唯一入口。
- **划词分析**：手动划词后可「加入 AI 分析」；实时语音模式下，未点加入的选区也可作为回答焦点。
- **页码跳转**：支持快捷跳转到指定页。

### 概览（中栏）
- **关键数据**：展示本期结构化关键指标与摘要。
- **出处角标**：指标旁页码角标一键跳转并高亮原文对应位置。
- **指标联动**：四项指标与趋势之间展示最多 3 条程序关系；标题样式与财报速览一致，内部条目默认折叠，点击查看事实和简短解读。仅展示，无查看依据、追问原因按钮，不重复原因待核验提示。
- **深度归因**：按行业属性维度解读财报变化，引入行业 skill 提示，优先展示有料维度（子标题精简）。

### 追问栏（右栏）
- **高效追问提示**：默认给出追问技巧引导。
- **组合上下文**：可通过 PDF 划词或卡片双击，按需组合内容后再问。
- **生成中态**：回答过程有明确等待/流式反馈。
- **可验证答案**：结论带 PDF 页码引用；点击角标跳转原文并高亮。
- **反馈**：赞 / 踩提交后进入审计记录，便于回灌与质检。
- **重答与篇幅**：可对同一问题重新回答，并调整长短。
- **复制答案**：一键复制。
- **相关问题**：生成约三个推荐追问，降低空白输入成本。
- **边界策略**：题外话短答 + 软提示（说明可能超出本份财报范围），避免硬拒误伤追问。

### 实时语音
- **连续对话**：支持实时语音交互（可打断、答完可继续听）。
- **跟页提问**：识别当前 PDF 页，对着当前页内容口述即可。
- **答后定位**：回答带出处时，可自动跳页并高亮相关原文。
- **语音切期次**：可用语音切换财报期次。
- **回首页换公司**：支持「返回主页 / 换一家」等说法，跨页保持语音会话，便于连续问不同公司。
- **告别退出**：如「退下吧」等说法会结束语音会话，并给出简短告别。
