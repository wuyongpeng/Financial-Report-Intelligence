# 指标关系层（规划）

> 状态：**规划中 / 下一迭代，尚未上线**。  
> 背景：单指标 + 同比 + 深度归因 + 追问已能「找得到」；决赛叙事里更有价值的是**数字之间的关系**（营收↑净利↓；账面盈利但经营现金流恶化）——这才是 AI 主场。

---

## 1. 原则

| 层 | 谁做 | 产出 |
|---|---|---|
| 硬事实 / 口令 | 本地规则 | 数字、同比符号、页码、翻页缩放 |
| 关系是否「值得看」 | 规则（少而硬） | 提示卡片，不下投资结论 |
| 关系「为什么」 | AI | 双出处解释，用户点「追问这条」才触发 |

一句话：**关系层建在可验证数字上；提示「值得看」，不替用户下结论。**

与既有口令原则一致：确定的走规则，不确定的解读走 AI。

---

## 2. 为何不全量复活「重点关注」

- UI 已下线：假阳性直接伤信任（见 `docs/product-feature-list.md` 附注、`data/watch-skills/README.md`）。
- 旧模块维数多（处罚/股东/分红/捐款/存贷双高…），阈值一松就刷屏。
- **做法**：不批发重开；只抽 **2～3 对硬勾稽**，文案只陈述现象 + 双出处，结论语气留给 AI 追问。

`lib/focus-highlights.ts` 可作实现素材，不是产品 UI 合同。

---

## 3. v1 范围（仅硬对）

每张卡固定形态：

1. **两个数字**（可带同比或净现比）  
2. **各自出处页码**（沿用中栏角标跳转）  
3. **一句现象**（「营收同比为正、归母净利同比为负」类，禁止「建议减持」）  
4. **「追问这条」** → 右栏 AI，prompt 带双出处，解释「为什么可能这样」

### (a) 营收同比 ↔ 归母净利同比 · 符号背离

- 条件：两边同比均可算（`resolveYoy` / `yoy_pct` 已有），且符号相反（一正一负）。
- 现象例：营收同比 +x%，归母净利同比 −y%。
- 数据：`lib/detail-model.ts` + `lib/crawl-display.ts`（`describeYoy` / `resolveYoy`）。

### (b) 归母净利 > 0 且经营现金流明显弱 / 恶化

- **复用**现有 `cash_vs_profit`（`lib/focus-highlights.ts` + `FOCUS_THRESHOLDS.cashToProfitRatio`）：
  - 净利 > 0 且 OCF < 0；或  
  - 净现比 `OCF / 净利` < 0.5  
- 现象例：归母净利 x 亿，经营现金流净额 y 亿（净现比 …）。
- 不下「造假」等定性词。

### (c) 第三对 · 可选

仅当解析器**两边数字都已稳定抽出**再加；候选优先已有规则素材（如非经常性损益占归母，见同文件），**没有把握就砍掉，宁缺毋滥**。  
v1 不为此新开解析字段。

展示上限：同时最多 **2** 张（沿用 `FOCUS_MAX_CARDS` 思路），避免中栏变排雷墙。
