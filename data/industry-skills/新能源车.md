# 二级 Skill：新能源车

| 字段 | 值 |
|---|---|
| id | `industry.nev` |
| 匹配二级 | `新能源车` |
| 一级兜底 | `新能源` |
| 示例公司 | 比亚迪 |

## 归因骨架（有原文才写模块）

- 量：汽车销量（新能源/分车型若披露）——有原文才写
- 价：单车均价或 ASP 线索——有原文才写
- 结构：国内/海外、车型或业务（整车/电池等）——有原文才写
- 毛利与费用：整车毛利率；研发/销售费用率——有原文才写
- 存货与现金流：存货、减值、经营现金流——有原文才写

## 指标口径

| 关注指标 | 口径说明 | 为何重要 |
|---|---|---|
| 销量 | 产销数据 | 量 |
| 均价/ASP 线索 | 收入÷销量或披露 | 价 |
| 毛利率 | 整车或分部 | 价格战 |
| 研发/销售费用率 | 利润表 | 投入与获客 |
| 存货/OCF | 报表 | 质量 |

**通用禁用误判：** 不要把可转债/定增公告当季报；EPS 不因「千元」表头换算；同比优先用「主要会计数据」披露列；无数据写「未披露」。

## 关注维度

1. 交付量与均价
2. 海内外结构
3. 毛利与价格战
4. 费用率
5. 存货与现金流

## 深度归因模块提示

| 模块 | 提示 |
|---|---|
| 主营业务 | 销量·均价·区域/车型结构；点明价格战。 |
| 净利润变动 | 毛利 + 费用 + 减值/投资收益。 |
| 异常指标 | 存货与价格战、大额减值、经营现金流与交付背离。 |

## 禁区

- 电池材料公司套用本 Skill
- 把行业渗透率预测写成公司销量
- 可转债当季报
- EPS 千元换算
