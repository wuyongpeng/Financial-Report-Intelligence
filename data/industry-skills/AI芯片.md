# 二级 Skill：AI芯片

| 字段 | 值 |
|---|---|
| id | `industry.ai-chip` |
| 匹配二级 | `AI芯片` |
| 一级兜底 | `科技` |
| 示例公司 | 寒武纪、沐曦股份-U |

## 归因骨架（有原文才写模块）

- 收入与结构：产品/客户收入拆分——有原文才写
- 毛利：毛利率与产品组合——有原文才写
- 研发与流片：研发费用率；流片/迭代相关披露（进展≠收入）——有原文才写
- 存货与减值：存货及跌价——有原文才写
- 大客户依赖与现金流：客户集中度、经营现金流——有原文才写

## 指标口径

| 关注指标 | 口径说明 | 为何重要 |
|---|---|---|
| 收入/毛利率 | 报表 | 商业化阶段 |
| 研发费用率 | 利润表 | 投入 |
| 存货及减值 | 报表 | 库存风险 |
| 客户集中 | 有则写 | 依赖 |
| OCF | 现金流 | 造血 |

**通用禁用误判：** 不要把可转债/定增公告当季报；EPS 不因「千元」表头换算；同比优先用「主要会计数据」披露列；无数据写「未披露」。

## 关注维度

1. 收入是否起量
2. 毛利
3. 研发强度
4. 存货
5. 客户依赖

## 检索关键词

`毛利率`、`研发费用`、`流片`、`存货`、`跌价`、`客户`、`经营现金流`、`芯片`、`加速`

## 深度归因模块提示

| 模块 | 提示 |
|---|---|
| 主营业务 | 收入结构 + 毛利；区分送测/流片进展与确认收入。 |
| 净利润变动 | 收入规模尚小时常被研发费用主导——写清费用强度。 |
| 异常指标 | 存货跌价、单客户依赖、经营现金流持续大额为负。 |

## 禁区

- 把流片成功写成已确认规模收入
- 套用银行或应用软件框架
- 可转债当季报
- EPS 千元换算
- 「AI 收入」虚构口径
