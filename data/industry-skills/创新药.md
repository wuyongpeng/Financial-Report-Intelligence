# 二级 Skill：创新药

| 字段 | 值 |
|---|---|
| id | `industry.innovative-drug` |
| 匹配二级 | `创新药` |
| 一级兜底 | `医药` |
| 示例公司 | 恒瑞医药 |

## 归因骨架（有原文才写模块）

- 收入结构：产品销售 / 授权 / 合作收入——有原文才写
- 研发：研发费用与管线进展（进展≠收入）——有原文才写
- 毛利：产品毛利率——有原文才写
- 现金：经营现金流与现金储备——有原文才写
- 授权收入是否一次性必须说清；禁止把临床进展写成已上市放量

## 指标口径

| 关注指标 | 口径说明 | 为何重要 |
|---|---|---|
| 收入结构 | 产品/授权 | 质量 |
| 研发费用 | 利润表 | 投入 |
| 毛利率 | 产品 | 盈利 |
| OCF/现金 | 报表 | 可持续 |
| 管线进展 | MD&A | 进展≠收入 |

**通用禁用误判：** 不要把可转债/定增公告当季报；EPS 不因「千元」表头换算；同比优先用「主要会计数据」披露列；无数据写「未披露」。

## 关注维度

1. 收入是否产品化
2. 授权是否一次性
3. 研发强度
4. 现金跑道
5. 毛利

## 检索关键词

`研发费用`、`授权`、`许可`、`毛利率`、`经营现金流`、`货币资金`、`管线`、`药品销售收入`

## 深度归因模块提示

| 模块 | 提示 |
|---|---|
| 主营业务 | 产品销售 vs 授权一次性；勿把管线进展当收入。 |
| 净利润变动 | 产品放量 + 授权确认节奏 + 研发费用。 |
| 异常指标 | 依赖单笔授权、现金快速消耗、研发资本化异常。 |

## 禁区

- 临床进展写成已上市放量
- 编造峰值销售
- 可转债当季报
- EPS 千元换算
