# 二级 Skill：银行

| 字段 | 值 |
|---|---|
| id | `industry.bank` |
| 匹配二级 | `银行` |
| 一级兜底 | `金融` |
| 示例公司 | 招商银行、工商银行、建设银行 |

## 归因骨架（有原文才写模块）

- 息差/NIM：净利息收益率、净利差及资产收益率/负债成本——有原文才写
- 规模：贷款或生息资产增速；利息净收入量价因素（有则写）
- 非息：非利息净收入及手续费结构（财富/银行卡等）——有原文才写
- 不良与拨备：不良贷款率、拨备覆盖率、信用减值对利润影响——有原文才写
- 禁止制造业毛利/存货话术；拨备少提推高利润必须点明

## 指标口径

| 关注指标 | 口径说明 | 为何重要 |
|---|---|---|
| NIM / 净利差 | 管理层补充财务指标 | 息差核心 |
| 利息净收入 / 生息资产或贷款 | 规模与量价 | 以量补价是否成立 |
| 非息收入及分项 | 手续费及佣金等 | 中收质量 |
| 不良率 / 拨备覆盖 / 信用减值 | 资产质量节 | 风险成本 |
| 资本充足率（核心一级等） | 有则写 | 扩表与分红约束 |

**通用禁用误判：** 不要把可转债/定增公告当季报；EPS 不因「千元」表头换算；同比优先用「主要会计数据」披露列；无数据写「未披露」。

## 关注维度

1. 息差怎么变；资产端与负债端谁主导
2. 利息净收入靠规模还是靠息差
3. 非息里财富/银行卡等谁强谁弱
4. 不良与拨备、信用减值对净利
5. 资本充足对扩张/分红约束（有披露）

## 深度归因模块提示

| 模块 | 提示 |
|---|---|
| 主营业务 | 量价（规模×息差）+ 非息结构；勿写毛利率主叙事。 |
| 净利润变动 | 息差与规模、非息、信用成本（拨备）三因子拆解。 |
| 异常指标 | NIM 骤降、不良迁徙、拨备覆盖大幅下行、投资收益一次性抬升。 |

## 禁区

- 制造业毛利率/存货周转框架硬套银行
- 只写净利大增却不点明拨备少提
- 可转债/资本债/定增公告当季报
- EPS 千元换算
- 无 NIM 数字时硬套利息收入/资产错分母
