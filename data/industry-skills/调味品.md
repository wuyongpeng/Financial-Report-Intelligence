# 二级 Skill：调味品

| 字段 | 值 |
|---|---|
| id | `industry.condiment` |
| 匹配二级 | `调味品` |
| 一级兜底 | `消费` |
| 示例公司 | 海天味业 |

## 归因骨架（有原文才写模块）

- 量价：收入；吨价/结构——有原文才写
- 毛利：毛利率——有原文才写
- 渠道：渠道库存线索、经销商与提价表述——有原文才写
- 销售费用率——有原文才写
- 经营现金流——有原文才写；关注提价能否落地与渠道消化

## 指标口径

| 关注指标 | 口径说明 | 为何重要 |
|---|---|---|
| 收入/吨价 | 原文 | 量价 |
| 毛利率 | 报表 | 盈利 |
| 销售费用率 | 利润表 | 渠道费用 |
| OCF | 现金流 | 质量 |
| 提价/库存表述 | MD&A | 仅限披露 |

**通用禁用误判：** 不要把可转债/定增公告当季报；EPS 不因「千元」表头换算；同比优先用「主要会计数据」披露列；无数据写「未披露」。

## 关注维度

1. 吨价结构
2. 毛利
3. 提价与渠道
4. 费用率
5. 现金流

## 深度归因模块提示

| 模块 | 提示 |
|---|---|
| 主营业务 | 吨价与结构 + 提价落地证据。 |
| 净利润变动 | 提价/成本 + 费用。 |
| 异常指标 | 费用升而收入平、渠道库存表述转弱。 |

## 禁区

- 无证据声称提价成功
- 可转债当季报
- EPS 千元换算
