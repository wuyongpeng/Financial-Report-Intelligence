# 二级 Skill：AI应用

| 字段 | 值 |
|---|---|
| id | `industry.ai-application` |
| 匹配二级 | `AI应用` |
| 一级兜底 | `科技` |
| 示例公司 | 海康威视、科大讯飞、金山办公 |

## 归因骨架（有原文才写模块）

- 分产品：谁增谁减（教育/开放平台/医疗/硬件等原文分部）——有原文才写
- 分产品毛利：高毛利 vs 低毛利产品消长对综合毛利含义——有原文才写
- 合同负债/回款：合同负债、合同额、销售回款与收入是否同向——有原文才写
- 研发强度：研发费用或研发投入占收比——有原文才写
- 禁止写「AI 收入」单一口径；进展叙述≠已确认收入

## 指标口径

| 关注指标 | 口径说明 | 为何重要 |
|---|---|---|
| 分产品收入与同比 | 营业收入构成表 | 结构重于总量 |
| 分产品毛利率 | 占收或利润 10% 以上表 | 单位经济 |
| 合同负债 | 资产负债表 | 需求能见度 |
| 研发投入/费用率 | MD&A + 利润表 | 投入强度 |
| 合同额/回款 | 管理层叙述（有则写） | 前瞻与回款质量 |

**通用禁用误判：** 不要把可转债/定增公告当季报；EPS 不因「千元」表头换算；同比优先用「主要会计数据」披露列；无数据写「未披露」。

## 关注维度

1. 哪条业务在撑增长、哪条在收缩
2. 收入向高/低毛利倾斜对综合毛利的含义
3. 合同负债、合同额、回款与收入增速是否同向
4. 研发占收是否解释利润波动
5. 区分技术进展叙述与已确认收入

## 检索关键词

`营业收入构成`、`分产品`、`占公司营业收入或营业利润10%以上`、`合同负债`、`研发投入`、`研发费用`、`合同额`、`回款`、`毛利率`

## 深度归因模块提示

| 模块 | 提示 |
|---|---|
| 主营业务 | 一张分产品表讲清增量与收缩；勿发明 AI 收入行。 |
| 净利润变动 | 结构毛利差异 + 研发/销售费用强度 + 一次性项目波动。 |
| 异常指标 | 合同负债背离收入、经营现金流长期为负、单业务断崖式下滑。 |

## 禁区

- 「AI 收入」作为默认 KPI（无统一披露口径）
- 把学习机市占/开发者数做成指标卡默认项
- 把展望/技术进展写成当期收入事实
- 算力硬件/IDC 公司套用本 Skill
- 可转债当季报；EPS 千元换算
