# 二级 Skill：CXO

| 字段 | 值 |
|---|---|
| id | `industry.cxo` |
| 匹配二级 | `CXO` |
| 一级兜底 | `医药` |
| 示例公司 | 药明康德 |

## 归因骨架（有原文才写模块）

- 收入与订单：营收；在手/新签订单（有则写）——有原文才写
- 毛利率——有原文才写
- 客户与地缘：客户结构及地缘相关披露——有原文才写
- 现金流与产能：经营现金流、实验室/产能 Capex——有原文才写
- 汇率影响——有原文才写；订单前景勿脱离原文

## 指标口径

| 关注指标 | 口径说明 | 为何重要 |
|---|---|---|
| 收入/订单 | 报表+MD&A | 景气 |
| 毛利率 | 报表 | 盈利 |
| 客户/地缘 | 有则写 | 风险 |
| OCF/Capex | 现金流 | 产能 |
| 汇兑 | 有则写 | 利润扰动 |

**通用禁用误判：** 不要把可转债/定增公告当季报；EPS 不因「千元」表头换算；同比优先用「主要会计数据」披露列；无数据写「未披露」。

## 深度归因模块提示

| 模块 | 提示 |
|---|---|
| 主营业务 | 收入 + 订单（有则）+ 客户结构。 |
| 净利润变动 | 订单转化节奏 + 毛利 + 汇兑。 |
| 异常指标 | 订单下滑、客户集中、汇兑巨震、Capex 与需求错配。 |

## 禁区

- 订单前景脱离原文臆测
- 可转债当季报
- EPS 千元换算
