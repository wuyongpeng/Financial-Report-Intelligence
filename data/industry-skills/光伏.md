# 二级 Skill：光伏

| 字段 | 值 |
|---|---|
| id | `industry.pv` |
| 匹配二级 | `光伏` |
| 一级兜底 | `新能源` |
| 示例公司 | 隆基绿能、阳光电源、通威股份 |

## 归因骨架（有原文才写模块）

- 量：组件/硅片/电池出货量（按公司主业环节）——有原文才写
- 价：产品均价或硅料/组件价格线索——有原文才写
- 毛利：分环节或综合毛利率；价格战冲击——有原文才写
- 存货与减值：存货及跌价/资产减值——有原文才写
- 现金流与资本开支：经营现金流、购建固定资产/净负债——有原文才写

## 指标口径

| 关注指标 | 口径说明 | 为何重要 |
|---|---|---|
| 出货量 | 原文销量/出货 | 量 |
| 产品价格/均价线索 | MD&A 或均价 | 价 |
| 毛利率 | 综合或分产品 | 价格战敏感 |
| 存货及减值 | 报表+说明 | 周期库存 |
| OCF / Capex | 现金流 | 扩产与偿债 |

**通用禁用误判：** 不要把可转债/定增公告当季报；EPS 不因「千元」表头换算；同比优先用「主要会计数据」披露列；无数据写「未披露」。

## 关注维度

1. 量增能否对冲价跌
2. 主业环节毛利
3. 存货与减值
4. Capex 与负债
5. 一体化 vs 单环节（有披露）

## 深度归因模块提示

| 模块 | 提示 |
|---|---|
| 主营业务 | 按公司主业环节写量价；点明价格战对收入/毛利。 |
| 净利润变动 | 价跌 vs 量增、减值、汇兑/费用。 |
| 异常指标 | 存货飙升、大额减值、经营现金流与净利背离。 |

## 禁区

- 把开工率当默认承诺（无%勿写）
- 混用锂电材料口径
- 可转债当季报
- EPS 千元换算
- 宏观装机预测写成公司已实现收入
