# 重点关注 Watch Skills（财报智析）

## 用途

- 概览「重点关注」最多展示 **2** 张动态卡片。
- 运行时按 `dimensions.json` 中约 10 个维度做规则/文本巡检（可挖「合法避重就轻」的坑）。
- 有信号的维度按严重度排序取 Top 2；**全部无信号**时展示两个 `default: true` 维度，文案为「暂无风险」类冷静表述。
- `{id}.md` 给人审与后续接 LLM 挖坑提示；页面加载默认走确定性规则，不每次调用模型。

## 原则

1. 只陈述事实与对比，不下投资结论、不评级。
2. 禁止四个「未发现…」空壳卡并排。
3. 数字优先来自结构化指标；单位/笔误类依赖页文本扫描。
4. 无披露写「暂无法判断」，未扫描到写「暂无风险」，不要写成「无异常」假装查过。

## 路径

- 仓库：`data/watch-skills/`
- 入口：`dimensions.json`
